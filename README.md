# PicTri

PicTri is an iOS travel-memory app built with Swift and SwiftUI. Discover a spot on the map, verify you're actually there, and take a photo — the picture becomes part of your personal travel record, shared only with friends you add.

- Platform: iOS (Swift / SwiftUI)
- Focus: location-verified travel photos, not a public social feed or ranking app

This is a private development repository. No public release yet.
